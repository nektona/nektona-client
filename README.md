# Nektona

VPN-клиент для macOS на ядре Xray. Работает с подписками любых провайдеров.

## Установка

1. Откройте [Releases](https://github.com/nektona/nektona-client/releases/latest) и скачайте `Nektona.dmg`.
2. Откройте образ и перетащите Nektona в «Программы».

Требуется macOS 26 на Apple Silicon.

Дальше приложение обновляется само: когда выходит новая версия, в нём появляется кнопка «Обновить».
