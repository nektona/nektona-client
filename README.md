# Nektona

VPN-клиент для macOS и Windows на ядре Xray. Работает с подписками любых провайдеров.

## Установка на macOS

1. Скачайте образ для macOS: [nektona-macos-arm64.dmg](https://github.com/nektona/nektona-client/releases/latest/download/nektona-macos-arm64.dmg) — это всегда последняя версия.
2. Откройте образ и перетащите Nektona в «Программы».

Требуется macOS 26 на Apple Silicon.

Дальше приложение обновляется само: когда выходит новая версия, в нём появляется кнопка «Обновить».

## Установка на Windows

1. Скачайте установщик для своего компьютера — это всегда последняя версия:
   - [nektona-windows-x64.exe](https://github.com/nektona/nektona-client/releases/latest/download/nektona-windows-x64.exe) — для большинства компьютеров (процессоры Intel и AMD);
   - [nektona-windows-arm64.exe](https://github.com/nektona/nektona-client/releases/latest/download/nektona-windows-arm64.exe) — для компьютеров на ARM (например, Snapdragon).

   Тип процессора указан в «Параметры → Система → О системе → Тип системы».
2. Запустите установщик и следуйте его шагам. Windows один раз попросит разрешить изменения на компьютере.

Если появится окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»: установщик пока не подписан сертификатом разработчика.

Требуется Windows 10 или 11. Новую версию ставьте так же — установщик заменит старую, настройки сохранятся. Удалить программу можно в «Параметры → Приложения».

---

A VPN client for macOS and Windows built on Xray; works with subscriptions of any provider. This repository holds the released builds only. Download the latest version: macOS — [nektona-macos-arm64.dmg](https://github.com/nektona/nektona-client/releases/latest/download/nektona-macos-arm64.dmg); Windows — [nektona-windows-x64.exe](https://github.com/nektona/nektona-client/releases/latest/download/nektona-windows-x64.exe) (Intel and AMD) or [nektona-windows-arm64.exe](https://github.com/nektona/nektona-client/releases/latest/download/nektona-windows-arm64.exe) (ARM).
