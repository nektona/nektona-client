# Nektona

VPN-клиент для macOS и Windows на ядре Xray. Работает с подписками любых провайдеров.

## Установка на macOS

1. Скачайте образ для macOS: [nektona-macos-arm64.dmg](https://github.com/nektona/nektona-client/releases/latest/download/nektona-macos-arm64.dmg) — это всегда последняя версия.
2. Откройте образ и перетащите Nektona в «Программы».

Требуется macOS 26 на Apple Silicon.

Дальше приложение обновляется само: когда выходит новая версия, в нём появляется кнопка «Обновить».

## Установка на Windows

1. Скачайте установщик: [nektona-windows-x64.exe](https://github.com/nektona/nektona-client/releases/latest/download/nektona-windows-x64.exe) (для ARM — [nektona-windows-arm64.exe](https://github.com/nektona/nektona-client/releases/latest/download/nektona-windows-arm64.exe)) — это всегда последняя версия.
2. Запустите установщик.

---

A VPN client for macOS and Windows built on Xray; works with subscriptions of any provider. This repository holds the released builds only. Download the latest version: macOS — [nektona-macos-arm64.dmg](https://github.com/nektona/nektona-client/releases/latest/download/nektona-macos-arm64.dmg); Windows — [nektona-windows-x64.exe](https://github.com/nektona/nektona-client/releases/latest/download/nektona-windows-x64.exe) (ARM: [nektona-windows-arm64.exe](https://github.com/nektona/nektona-client/releases/latest/download/nektona-windows-arm64.exe)).
